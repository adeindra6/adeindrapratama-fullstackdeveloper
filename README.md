# Indokerja.id

## How to run this project

### Backend
1. `cd indokerja-be`
2. run `npm install`
3. create a postgresql database
4. run `cp .env.example .env`
5. edit DATABASE_URL within your machine setup
6. run `npx prisma generate`
7. run `npm run dev`

### Frontend
1. `cd indokerja-fe`
2. run `npm install`
3. run `npm run dev`
